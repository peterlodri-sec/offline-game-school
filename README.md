# Offline Game School

**Free, offline, runnable lessons in logic and computer thinking — built as
fun and retro games in plain JavaScript. No internet. No install. No cost.**

Open any game file in a browser (double-click the `.html`), and it just runs.
Every game is ONE self-contained file — no libraries, no downloads, no
accounts. This works on old laptops, cheap phones, and school computers that
have no network.

Built for kids and for people learning with little or nothing — starting with
the students and families supported by
[RUN ANGELLA MATHEW CENTER UGANDA LTD](https://github.com/kadondibetty)
(kadondibetty) — a center in Uganda that pays tuition and school supplies for
orphans and vulnerable children.

## Why games?

You learn to think like a computer by building and playing with logic. Every
game here teaches a real computer-science idea, and every game can be opened
and changed by the learner. The code is the lesson.

| Game | File | What you learn |
|---|---|---|
| Guess the Number | `games/guess-the-number.html` | loops, if/else, binary search |
| Rock Paper Scissors | `games/rock-paper-scissors.html` | conditions, random, counters |
| Tic Tac Toe | `games/tic-tac-toe.html` | 2D arrays, win checking |
| Snake | `games/snake.html` | arrays, timers, collision, state |
| Mastermind | `games/mastermind.html` | logic deduction, feedback loops |
| Memory Match | `games/memory-match.html` | arrays, events, shuffle |
| Age of Gaia | `games/age-of-gaia.html` | entities, game loop, economy, waves, targeting — a tiny real-time strategy |

## How to use (offline, no internet)

1. Copy the `games/` folder to any computer or phone (a USB stick works).
2. Double-click a game file. It opens in the browser.
3. Play. Then open the file in a text editor (Notepad, or any editor) and
   change one number — see what breaks and what changes.
4. Read the matching `lessons/` playbook for the idea behind the game and the
   "make it yours" challenge.

Everything works on a school computer that has never seen the internet.

## The project-based path (like OSSU, but in one repo)

OSSU is a famous free self-taught computer-science curriculum. This repo is
the same idea, project-first: you learn by completing each game as a project.

### Stage 1 — Logic (days 1-5)
1. Guess the Number — conditionals, `if`, `while`, numbers.
2. Rock Paper Scissors — `if/else`, `Math.random()`, keeping score.
3. Memory Match — arrays, shuffle, events, state.

### Stage 2 — Structure (days 6-10)
4. Tic Tac Toe — 2D arrays, win conditions, functions.
5. Mastermind — nested loops, feedback, deduction.

### Stage 3 — Real games (days 11-15)
6. Snake — arrays of parts, timers, collision, game over.
7. Capstone project: build YOUR OWN game (see `lessons/capstone.md`).

Every playbook has: **What is it** · **The idea** · **Map it in the code** ·
**Try this** · **Make it yours** (a small next project).

## Rules for the repo

- Every game is ONE file, plain HTML+CSS+JS, no libraries, no network calls.
- Must run on an old browser and on a touchscreen phone.
- English must be simple; buttons big; no mouse-only controls.
- You can copy, change, and give this away freely (MIT license).

## For teachers and mentors

Each `lessons/` file is a 20-30 minute session. The game is the warm-up; the
playbook explains the idea; "Make it yours" is the homework. You do not need
to be a programmer to mentor — the playbooks are written to be read aloud.
